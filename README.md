## Current Projects

### Atlas Homepage

A self-hosted infrastructure dashboard built to monitor and manage my homelab environment.

Atlas Homepage acts as a central control panel for my devices, services, and system information. The project combines a modern web frontend with backend monitoring services to provide real-time visibility into my infrastructure.

Features include:

- Real-time device monitoring and status tracking
- Individual device dashboards with system telemetry
- CPU, memory, disk usage visualisation
- Backend API built with FastAPI
- Next.js and React frontend
- Docker-based service management
- Integration with Linux servers and self-hosted services
- Responsive dashboard design inspired by modern infrastructure tools

Technologies explored:

- TypeScript / React / Next.js
- FastAPI / Python
- Linux administration
- REST APIs
- Docker
- Networking and system monitoring

This project is part of my ongoing effort to build practical experience in DevOps, cloud engineering, infrastructure automation, and system architecture.

### Project Olympus

A continuously evolving homelab and infrastructure learning environment focused on developing practical skills in Linux administration, networking, automation, and self-hosted services.

Project Olympus documents my journey building and maintaining a personal infrastructure environment while experimenting with real-world system administration concepts.

Areas explored:

- Linux server administration across Ubuntu and Fedora environments
- Self-hosted services using Docker and containerisation
- Network configuration, DNS, and remote access
- SSH-based server management
- Service monitoring and uptime tracking
- Reverse proxies and web service deployment
- Infrastructure automation and configuration management
- Hardware and virtualisation experimentation

Technologies and tools:

- Linux (Ubuntu / Fedora)
- Docker & Docker Compose
- Nginx
- Tailscale
- SSH
- Raspberry Pi
- Networking fundamentals
- Self-hosted applications

Project Olympus serves as the foundation for my understanding of how modern infrastructure operates, from individual services to larger cloud and DevOps environments.

### Blockchain & MEV Research

Research and experimentation into Ethereum transaction systems, blockchain analytics, and Maximal Extractable Value (MEV).

This project explores how blockchain transactions are processed, analysed, and optimised by studying transaction ordering, arbitrage opportunities, and on-chain data.

Areas explored:

- Ethereum transaction analysis
- MEV concepts and detection methods
- Blockchain data processing
- Transaction ordering and execution behaviour
- Arbitrage opportunity analysis
- Data visualisation and analytical tooling

Technologies and tools:

- Python
- Web3 technologies
- Blockchain APIs
- Data analysis libraries
- NumPy / Pandas
- Matplotlib
- Ethereum ecosystem tooling

The project combines software engineering, data analysis, and distributed systems concepts to better understand the infrastructure and economic mechanisms behind decentralised networks.
